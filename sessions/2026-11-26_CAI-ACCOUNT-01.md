# Nhật ký phiên làm việc: Triển khai Account Management & User Profile Dropdown (CAI-ACCOUNT-01)

- **Ngày thực hiện**: 2026-11-26
- **Nhiệm vụ**: Module Quản lý tài khoản người dùng & Dropdown cá nhân trên Navbar (`CAI-ACCOUNT-01`)
- **Trạng thái**: **DONE (chờ duyệt ACCEPTED)**

---

## 1. Mục tiêu phiên làm việc
Triển khai module Quản lý tài khoản cho ComicAI / BlueToon:
1. User Dropdown Menu trên Navbar khi hover/click tên người dùng hoặc avatar.
2. Hiển thị avatar người dùng kèm cơ chế fallback chữ cái đầu thông minh, chống ảnh vỡ.
3. Cập nhật thông tin cá nhân (họ tên, email).
4. Upload và thay đổi avatar (validate MIME, dung lượng tối đa 2MB, xóa file cũ an toàn).
5. Đổi mật khẩu với đầy đủ kiểm tra bảo mật (mật khẩu hiện tại, policy mật khẩu, xác nhận khớp).
6. Tích hợp trạng thái đăng ký Tác giả (Creator) theo 4 kịch bản nghiệp vụ.
7. Hiển thị vai trò và cập nhật trạng thái tức thì không cần reload trang.

---

## 2. Các thay đổi đã thực hiện

### Backend:
1. `backend/app/Http/Requests/UpdateProfileRequest.php`: Validate họ tên và email, bắt buộc quyền sở hữu.
2. `backend/app/Http/Requests/UploadAvatarRequest.php`: Validate tệp ảnh jpeg/png/webp, kích thước <= 2048KB.
3. `backend/app/Http/Requests/UpdatePasswordRequest.php`: Validate mật khẩu hiện tại, mật khẩu mới, xác nhận mật khẩu.
4. `backend/app/Http/Controllers/Api/AccountProfileController.php`: Xử lý 5 endpoints `show`, `update`, `uploadAvatar`, `deleteAvatar`, `updatePassword`.
5. `backend/app/Http/Resources/UserResource.php`: Bổ sung trường `avatar_url` chuẩn hóa từ Storage public disk.
6. `backend/routes/api.php`: Đăng ký 5 routes dưới middleware `auth:sanctum`, `active`, và `throttle:10,1`.
7. `backend/tests/Feature/AccountProfileApiTest.php`: 16 test cases kiểm thử validation, bảo mật, upload file, đổi mật khẩu và phân quyền.

### Frontend:
1. `frontend/src/types/auth.ts`: Bổ sung trường `avatar_url` và các interface payload.
2. `frontend/src/stores/auth.ts`: Bổ sung `setUser()` để cập nhật state reactive ngay lập tức khi người dùng sửa profile/avatar.
3. `frontend/src/services/accountService.ts`: Cung cấp các hàm API call cho tài khoản người dùng.
4. `frontend/src/components/AppHeader.vue`:
   - Xây dựng User Dropdown với tương tác hover và click, click outside, phím Escape.
   - Header banner dropdown với avatar lớn, tên, email, vai trò.
   - Menu items: Hồ sơ cá nhân, Cập nhật thông tin, Đổi mật khẩu, Trạng thái Creator tương ứng, Đăng xuất.
5. `frontend/src/pages/AccountProfilePage.vue`: Trang quản lý tài khoản với 3 tabs (Thông tin cá nhân, Đổi mật khẩu, Trạng thái Tác giả).
6. `frontend/src/router/index.ts`: Đăng ký route `/profile` và redirect `/account` -> `/profile`.
7. `frontend/src/pages/UserProfilePage.vue`: Tích hợp nút "Quản lý tài khoản ⚙️" cho profile của chính mình.
8. `frontend/src/composables/useNotificationRealtime.ts`: Tự động gọi `authStore.fetchUser()` khi nhận event `creator_application_approved`.
9. `frontend/tests/unit-account-dropdown.mjs`: Bộ 6 test suites kiểm tra toàn diện.
